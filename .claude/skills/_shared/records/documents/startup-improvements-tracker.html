P7Background-work scheduling experiment, judged by placement checks — NOT by TTID — defer-vs-overlap variants of the SDK's in-window background threads (15–19 ms CPU on entry tier). Acceptance criterion revised 2026-08-15: the original rule ("only a win if TTID improves") is unusable, because TTID's minimum detectable effect on this fleet is ~80 ms against predicted effects of ~15 ms — blind by 5×, so TTID would return "no change" whether the work was removed or merely moved.
